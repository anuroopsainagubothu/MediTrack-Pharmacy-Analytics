# 01 - Data Management

This folder contains information about the datasets used in the MediTrack Pharmacy Sales & Inventory Analytics project.

## Dataset Source

**Dataset:** Indonesian Retail Pharmacy Sales and Stock Transaction Dataset (2023–2025)

**Source:** Mendeley Data

**Download:** https://data.mendeley.com/datasets/w6zjtdjk9m/2

## Datasets

### 1. Pharmacy Sales Dataset
- Invoice details
- Transaction date and time
- Medicine information
- Quantity and pricing
- Discounts and revenue
- Payment methods

### 2. Pharmacy Stock Dataset
- Warehouse information
- Medicine details
- Initial stock
- Stock received
- Stock issued
- Remaining stock

## Data Handling

- Original raw CSV files are maintained outside this GitHub repository because of their large file sizes.
- Cleaned datasets are prepared using Python and Pandas.
- Processed data is used for SQL analysis and Power BI dashboards.

## Folder Structure

- Raw/ – Original source datasets (not uploaded).
- Cleaned/ – Cleaned and processed datasets.

## Purpose

To prepare reliable pharmacy sales and inventory data for analysis using Python, MySQL, and Power BI.
