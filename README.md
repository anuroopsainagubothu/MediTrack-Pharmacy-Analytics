# MediTrack – Pharmacy Sales & Inventory Analytics

## Project Overview

MediTrack is a data analytics project focused on analyzing pharmacy sales performance and inventory operations. The project uses data analytics tools to identify sales trends, understand product performance, monitor stock movements, and generate business insights through interactive dashboards.

## Business Problem

Pharmacies handle large volumes of sales and inventory transactions. Without proper analysis, it can be difficult to identify sales patterns, monitor stock levels, understand product demand, and make informed business decisions.

MediTrack addresses these challenges through data cleaning, SQL analysis, Python-based exploration, and Power BI dashboards.

## Project Objectives

- Analyze pharmacy sales and revenue performance.
- Identify top-performing medicines and product categories.
- Understand monthly and yearly sales trends.
- Analyze payment methods and sales patterns.
- Monitor stock-in and stock-out movements.
- Identify positive, zero, and negative stock records.
- Highlight potential inventory management issues.
- Present insights through interactive dashboards.

## Dataset Overview

The project uses two datasets:

### 1. Pharmacy Sales Dataset
Contains transaction-level sales information, including:
- Invoice details
- Transaction date and time
- Medicine names and codes
- Manufacturer and category
- Quantity and unit price
- Discounts and fees
- Payment type
- Total sales amount

### 2. Pharmacy Stock Dataset
Contains inventory transaction information, including:
- Warehouse details
- Medicine names and codes
- Initial stock
- Stock received
- Stock issued
- Remaining stock
- Drug category and type
- Stock transaction details

## Project Workflow

1. Data Collection – Obtained pharmacy sales and inventory datasets.
2. Data Exploration – Inspected rows, columns, data types, and data quality.
3. Data Cleaning – Processed the datasets using Python and Pandas.
4. Data Storage – Worked with MySQL for structured data analysis.
5. SQL Analysis – Developed queries to answer business questions.
6. Data Visualization – Created interactive dashboards using Power BI.
7. Insights – Examined sales performance and inventory trends.
