# 03 – SQL Analysis

This folder contains SQL scripts developed for the MediTrack Pharmacy Sales & Inventory Analytics project.

MySQL was used to query, analyse, and extract meaningful business insights from pharmacy sales and inventory datasets.

## Key SQL Activities

- Database and table creation
- Data exploration and validation
- Aggregate functions (SUM, COUNT, AVG, MIN, MAX)
- GROUP BY and HAVING
- Filtering using WHERE
- INNER JOIN and LEFT JOIN
- Subqueries and Common Table Expressions (CTEs)
- Date-based analysis
- CASE statements
- Business performance analysis

## Business Analysis

### Sales Analysis
- Total sales revenue
- Monthly and yearly revenue trends
- Sales performance by category
- Top-performing medicines
- Payment method analysis
- Average invoice value

### Inventory Analysis
- Stock-in and stock-out movements
- Inventory analysis by warehouse
- Positive, zero, and negative stock records
- Low-stock identification
- Medicine-level inventory analysis

## Tools Used

- MySQL
- MySQL Workbench

## Business Value

SQL helped transform transactional data into meaningful business insights, supporting sales performance evaluation and inventory monitoring.
