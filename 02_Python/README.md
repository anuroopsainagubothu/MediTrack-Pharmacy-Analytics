# 02 – Python Analysis

This folder contains the Python notebooks and scripts developed for the MediTrack Pharmacy Sales & Inventory Analytics project.

Python was used for data exploration, data cleaning, preprocessing, and preparing datasets for further analysis.

## Key Activities

- Exploratory data Analysis (EDA)
- Dataset inspection and understanding
- Data structure and data type analysis
- Missing value identification and treatment
- Duplicate record checks
- Data cleaning and preprocessing
- Feature engineering and calculated columns
- Data validation and consistency checks
- Preparing cleaned datasets for MySQL and Power BI

## Folder Structure

```text
02_Python/
├── Notebooks/
└── Scripts/
```

## Libraries Used

- Pandas
- NumPy
- Matplotlib
- Seaborn
- MySQL Connector/Python

## Business Value

Python helped transform raw pharmacy transaction data into structured datasets suitable for sales performance analysis and inventory monitoring.

## Outputs

Cleaned and validated sales and stock datasets used in subsequent SQL analysis and Power BI dashboard development.
