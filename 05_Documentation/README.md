# 05 – Project Documentation

This folder contains the documentation for the MediTrack Pharmacy Sales & Inventory Analytics project.

## Documentation Contents

### 1. Project Overview
Introduction, objectives, business problem, project scope, and technology stack.

### 2. Business Questions
Key business questions addressed through sales and inventory analysis.

### 3. Key Findings
Important insights identified from pharmacy sales transactions and inventory movements.

### 4. Data Dictionary
Descriptions of dataset columns, data types, and their business meanings.

## Project Objectives

- Analyse pharmacy sales performance.
- Identify revenue trends and top-performing medicines.
- Evaluate stock-in and stock-out movements.
- Identify negative, zero, and low-stock records.
- Build interactive dashboards for business monitoring.

## Technology Stack

Python | MySQL | Power BI | Excel
